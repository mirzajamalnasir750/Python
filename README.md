# Python Learning and Data Analysis

This repository contains my Python practice and learning materials, covering Python fundamentals, NumPy, Pandas, and data visualisation.

## Topics Covered

- **Python:** Basic programming concepts and practical exercises.
- **NumPy:** Numerical computing, arrays, and mathematical operations.
- **Pandas:** Data manipulation, data cleaning, filtering, and analysis.
- **Data Visualisation:** Learning to represent data through charts and graphs.
- **Jupyter Notebook:** Practical coding exercises and experiments.
- **Datasets:** Working with CSV files for data analysis practice.

## Repository Contents

- `Python_Basics.ipynb` — Python fundamentals.
- `NUMPY.ipynb` — NumPy practice.
- `PANDAS.ipynb` — Pandas practice.
- `student_dataset_1000_rows.csv` — Dataset for practising data analysis.

## Tools and Technologies

Python | NumPy | Pandas | Jupyter Notebook | Data Visualisation

My goal is to strengthen my Python programming and data analysis skills through practical exercises, working with datasets, and learning different techniques for analysing and visualising data.

This repository is a collection of my ongoing learning and practice in Python and data science.
